# BICHUX DEVSTUDIO

> Premium websites, e-commerce stores, and custom digital solutions.

## Overview

BICHUX DEVSTUDIO is a modern, responsive website template designed for a web development agency. It showcases services, pricing, projects, and a clean portfolio layout — built with vanilla HTML, CSS, and JavaScript.

**Live Demo:** [bichux.dev](https://bichux.dev)

## Features

- 🎯 **Fully Responsive** — Optimized for desktop, tablet, and mobile
- 🎨 **Modern Aesthetic** — Clean typography with dark theme
- ⚡ **Performance Focused** — No external dependencies (except Google Fonts)
- 🧩 **Modular Sections** — Services, Portfolio, Pricing, Process, and more
- 📱 **Mobile Menu** — Hamburger navigation with smooth toggle
- 🔍 **Active Navigation** — Highlights current section via Intersection Observer
- 🖼️ **Image-Ready** — Placeholder structure for hero and project visuals

---

## Tech Stack

| Technology | Purpose |
|------------|---------|
| HTML5 | Semantic markup |
| CSS3 | Custom styling with CSS variables |
| Vanilla JavaScript | Interactivity and navigation |
| Google Fonts | Manrope, Space Grotesk, DM Mono |
| Intersection Observer | Scroll-based active nav highlighting |
